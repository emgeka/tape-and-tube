Tape & Tube is a Windows adaptation of NTSCRT by Finn McKenty.
https://github.com/finnmckenty/NTSCRT

Own application and host integration: GPL-3.0-only.
Third-party components retain their own licenses and attribution.

All seven CRT presets, original notices, license review and matching own
source ZIP are included. Known upstream shader-scope uncertainties are
documented, following the project's adopted upstream-oriented policy.

This beta is unsigned. Setup optionally downloads a checksum-pinned FFmpeg
build directly from Gyan Doshi / gyan.dev (GPL v3), or uses your own tools.
The download is not embedded in this installer. Original license and build
documentation accompany the downloaded tools; see licenses\ffmpeg.
Required Microsoft runtimes are checked. DirectX can be downloaded from
Microsoft, verified and extracted automatically; DXSETUP then shows its
own license and administrator prompts. System components are not silently
installed. The actual DirectX component is checked again afterwards.

VirtualBox: CRTSim exports may contain black frames. This was not
reproduced on the physical host with the same source and preset.
